# Customer Churn Prediction

Projeto de análise exploratória e previsão de cancelamento de clientes utilizando o dataset IBM Telco Customer Churn.

## Objetivo

Identificar fatores relacionados ao cancelamento de clientes e desenvolver um modelo de Machine Learning capaz de prever churn.

## Tecnologias

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
